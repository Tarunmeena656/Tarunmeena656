## About

I build backend systems and AI products that have to work every day, not just in a demo. My recent work is
LLM applications on top of solid APIs: retrieval pipelines, tool-calling agents, and approval flows that keep a
human in control of anything the model sends or changes. I care about cost, latency and clear failure modes as
much as about features.

Currently a Backend Developer at Rootlex Technology. MCA from RGPV, Bhopal.

## What I work on

- **AI products** – RAG over private documents, embeddings and vector search, agents with tool calling, prompt and
  evaluation design, human-in-the-loop approval before any outbound action.
- **Backend services** – Node.js/TypeScript and Python/FastAPI, REST APIs, authentication (JWT, RBAC, OAuth),
  caching, background jobs, PostgreSQL and MongoDB at scale.
- **Cloud and operations** – AWS (Lambda, S3, EC2, API Gateway), Docker, NGINX, cost and performance tuning.
- **Integrations** – Stripe, Razorpay, WhatsApp, FCM, document workflows, Puppeteer and Cheerio scrapers.
