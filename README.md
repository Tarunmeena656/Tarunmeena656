## About

Full-stack and backend developer with close to four years of production experience. I build REST APIs and web
applications with the MERN stack, NestJS, Next.js and FastAPI, and I deliver features end to end, from the
database schema to the React screen. My recent work is LLM applications that have to run every day, not just in
a demo: retrieval pipelines, order extraction from messy input, and approval flows that keep a human in control
of anything the model publishes or sends. I care about cost, latency and clear failure modes as much as features.

## What I work on

- **AI products** – RAG over private documents, hybrid BM25 and vector retrieval, tool-calling agents, structured
  output validation and guardrails, human-in-the-loop approval before any outbound action.
- **Backend services** – Node.js and TypeScript (Express, NestJS, Fastify) and Python (FastAPI, Django, Celery),
  REST APIs, JWT, RBAC and OAuth, caching, queues, PostgreSQL and MongoDB at 300M+ record scale.
- **Frontend** – React and Next.js interfaces for review, approval and admin workflows, Tailwind, Redux.
- **Cloud and operations** – AWS (Lambda, S3, EC2, API Gateway), Docker, Kubernetes, CI/CD, NGINX, cost tuning.
- **Integrations** – Stripe, Razorpay, WhatsApp, FCM, Puppeteer and Cheerio scrapers, document workflows.

## How I build

- Nothing leaves the system without a human approving the exact content. Drafts are cheap; sends are not.
- Every record keeps its provenance: where it came from, when, and how confident the system is.
- Scores and decisions are explainable in plain language, and missing information is reported as unknown, never guessed.
- Cost-aware by default: rule-based paths first, the model only where it changes the result, every call measured.
